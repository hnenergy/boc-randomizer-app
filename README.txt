SPINORDER DRAFT RANDOMIZER — INSTALLABLE APPLICATION

This folder is ready to deploy as a static Progressive Web App (PWA).

DEPLOYMENT
1. Upload the entire folder to any HTTPS static host, such as Vercel.
2. Open the resulting HTTPS address in Safari on the iPhone.
3. Tap Share, then Add to Home Screen.
4. Launch SpinOrder Draft Randomizer from the new Home Screen icon.

IMPORTANT
- Keep all files together in the deployed root folder.
- Opening index.html directly from a ZIP or Files app will not enable installation or offline support.
- Use NEW DRAFT or START NEW DRAFT to reset and spin again after all picks are complete.
